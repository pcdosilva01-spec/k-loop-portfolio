# K/LOOP — PORTFÓLIO PESSOAL
## FRONTEND DESIGN + IMPLEMENTAÇÃO COMPLETA

Você vai criar e implementar um portfólio profissional completo para a K/LOOP.

ANTES DE QUALQUER ALTERAÇÃO NO CÓDIGO, LEIA E APLIQUE A SKILL DE FRONT-END DESIGN DISPONÍVEL NO AMBIENTE.

Se a skill estiver instalada, procure e leia primeiro:

.claude/skills/frontend-design/SKILL.md

Caso o ambiente utilize outra localização para skills, localize a skill equivalente de Frontend Design antes de continuar.

A skill deve ser usada como PRINCÍPIO DE DIREÇÃO DE ARTE E IMPLEMENTAÇÃO, não apenas como referência opcional.

Não comece criando componentes.

Primeiro analise o briefing, o projeto existente, a identidade visual, os assets e a referência visual. Depois defina uma direção visual coerente e só então implemente.

==================================================
01. OBJETIVO
==================================================

Criar um portfólio pessoal para:

K/LOOP

A K/LOOP é uma identidade profissional pessoal de um freelancer que trabalha com:

- web design
- desenvolvimento de sites
- landing pages
- e-commerce
- Nuvemshop
- interfaces digitais
- design
- projetos personalizados

A marca não deve parecer uma agência tradicional.

Existe uma pessoa real por trás da K/LOOP.

O site precisa apresentar o profissional através do trabalho produzido, e não através de uma quantidade exagerada de texto institucional.

Posicionamento da identidade:

“K/LOOP — do conceito ao clique.”

A proposta central é:

DESIGN + CÓDIGO + COMÉRCIO DIGITAL

==================================================
02. REGRA PRINCIPAL: FRONTEND DESIGN
==================================================

Aplique profundamente os princípios da Frontend Design Skill.

Não crie uma interface genérica de IA.

Não utilize o padrão:

hero genérica
+
texto centralizado
+
botão roxo
+
cards iguais
+
seção de serviços
+
footer previsível.

Esse resultado é PROIBIDO.

O objetivo é criar uma experiência visual com direção de arte própria.

Antes de implementar:

1. analise a identidade K/LOOP;
2. identifique os elementos visuais distintivos;
3. defina uma linguagem visual própria;
4. determine hierarquia;
5. determine composição;
6. determine ritmo entre as seções;
7. determine como os projetos serão apresentados;
8. só depois transforme isso em código.

O site precisa parecer deliberadamente projetado por um designer.

Não parecer “um template bonito”.

+

+

+

+

+

- dashboard
- agência corporativa
- software empresarial

- “AI website template”
- glassmorphism exagerado
- excesso de gradientes
- excesso de cards
- excesso de bordas
- excesso de sombras
- excesso de efeitos neon

A K/LOOP precisa possuir uma assinatura visual própria.

Use o símbolo K como elemento gráfico quando fizer sentido.

Explore:

- elementos deslocados
- grids quebrados
- camadas

- relações entre formas e texto.

Não transforme essas possibilidades em uma checklist.

Use apenas aquilo que realmente melhorar a composição.

23. MOTION DESIGN
==================================================

Use movimento como parte da experiência.

Possibilidades:

- reveal
- scroll animation
- text animation
- project image transitions
- hover
- parallax muito leve
- movement no símbolo K
- transitions.

Mas movimento NÃO pode dominar o conteúdo.

Evitar:

- animações infinitas desnecessárias
- delays artificiais
- efeitos pesados
- layout shift.

Implementar:

prefers-reduced-motion.
